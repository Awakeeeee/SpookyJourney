
### 概述
强调搜打撤体验的Roguelike地牢战斗玩法；
2D游戏；
Top-Down视角；

### MVP版本实现需求

1. 单房间战斗
玩家控制单个角色移动，角色自动攻击，移动中也可以攻击；
杀怪得到经验，经验用于升级，升级随机三选一，可以新增武器或强化现有能力；
单房间战斗方式可以参考《土豆兄弟》；

- 节奏
单房间内是短时间型的战斗，在1分钟以内；
敌人分几波出现；每个敌人出现前1s，生成点有提示；
角色升级发生在任何经验满的时候，而不是房间胜利时刻；

- 武器类型
剑：向角色两侧挥砍
飞刀：随机索敌，发射飞刀，可穿透
魔杖：随机索敌，发射火球，遇敌爆炸

- 强化项
待定


2. 地牢地图
地图由单个房间连接构成，随着推进，房间通过后不能再回来，即每个房间后做唯一的分叉式选择，这一点类似《杀戮尖塔》；
随着地图推进，难度整体上增强，在局内难度控制上，"地牢推进的深度"应是核心调节参数；
房间无限生成，不是传统Roguelike的打败BOSS后结束，这一点用于结合后续的搜打撤机制；


3. 局内的搜打撤结合
玩家从房间战利品中获得两大类道具：商品物资（例如黄历、灯泡、毛笔等物品的包装），特殊货币（例如黄晶、银钱等非通货货币的概念）；
这些道具需要带出局外卖钱，或用于升级养成；而不是局内使用；
如果安全撤离，带出全部道具；如果局内死亡，暂定只能带走40%的战利品；

- 搜索
每个房间都有一个保险箱，战斗中锁定，战斗胜利后可以打开；
靠近后显示按钮点击打开，打开后类似大型搜打撤游戏，界面显示保险箱背包和自身背包，保险箱背包中物品逐个读条出现，玩家可通过拖拽操作放入自己背包；
设计说明：这个搜索机制在功能上可以简化，但是仍然保持完整操作是为了搜索体验、模拟搜刮战利品的过程；
暂时不做背包整理，所有物品都只占1个格子；

- 撤离
撤离和房间连接机制紧密结合，期望是做成“房间层级的撤离决策”的体验；
每个房间返程后，都有2~3的入口可选择，对应不同类型的后续房间：
战斗房：普通战斗+宝箱的房间；
精英房：特别标注有精英怪的战斗，宝箱奖励更好；
BOSS房：有BOSS的战斗，宝箱奖励更好；
安全撤离房：结合搜打撤的关键点，一定几率刷出安全撤离的房间，进入房间后站到指定地点，10s后结束局内游戏，带走全部战利品；
战斗撤离房：坚持20s的战斗后方可安全撤离；
恢复房：站在指定地点，读条2s后恢复30%生命值；

- 奖励预览
选择房间时，表现形式是类似展开大地图；地图上前方有宝箱的房间，需要明确标注宝箱，玩家点击后，可以显示该宝箱有可能出产的部分道具；
这一点可以参考《三角洲行动》中大地图保险箱或任务的奖励预览形式；


4. 局外暂时简化
MVP版本做最简局外功能，只需要一个界面表示这是局外，支持商品卖钱、进入局内2个功能即可；
商品卖钱：即一个商店界面，上方是商店，下方半屏是玩家背包，可以拖拽卖出，或一键快速全部卖出。大致功能可以服用局内宝箱拿东西时的功能；
进入局内：有个入口点击后开始一局新游戏，MVP暂不区分多类型的局内地图；
